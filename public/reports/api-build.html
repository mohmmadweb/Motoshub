03 نیاز به تأیید تو

چند تصمیم که بهتره قبل از پوش روشن شوند.

  • Permissionها روی سایتِ نصب‌شده: بلوک authorization در install.php فقط موقع نصب تازه اجرا می‌شود. روی نصبِ فعلی motonext باید actionهای جدید (list/show/update/delete هر گروه) دستی یا با اسکریپت آپدیت اضافه شوند، وگرنه روت‌ها 403 می‌دهند. یک migration کوچک برایش می‌نویسم اگر بخواهی.
  • قرارداد تاریخ: Unix timestamp یا رشته‌ی شمسی؟ (فعلاً Unix).
  • وابستگی iisvideoplus برای افزودن ویدیو — باید روی سرور فعال باشد.
  • composer dump-autoload بعد از افزودن psr-4 لازم است (مرحله‌ی استقرار روی سرور).

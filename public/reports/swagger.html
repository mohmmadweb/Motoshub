Motoshub API v1 — 161 endpoints مرجع فارسی Postman openapi.json همه اسناد
این اسپک مستقیماً از سورس برنچ API تولید شده است. برای «Try it out» سرور https://motonext.shub.ir/api را انتخاب کنید — endpointهای جدید پس از merge و اجرای composer dump-autoload && php motoshub api:permissions-migrate روی سرور فعال می‌شوند. ابتدا POST /v1/auth/login را فراخوانی کنید و توکن را با دکمه‌ی Authorize وارد کنید.
